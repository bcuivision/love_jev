# 推荐原因 · 2026-09-27

推荐逻辑：先判断关系阶段及眼前的情绪/互动信号，再选择行动和期望结果，最后生成并筛选回复。默认界面只保留一句推荐、问号与填入按钮。

- `01-collapsed.png`：iPhone 17 Pro Max / iOS 26.5，默认收起状态。
- `02-expanded.png`：点击问号后，在按键区域展开原因。上方推荐保持可见，说明可滚动，右上角关闭恢复键盘。
- `03-compact-width.png`：iPhone 17 Pro / iOS 26.0，较窄屏幕上的推荐排版。
- `04-expanded-compact-width.png`：较窄屏幕上的原因面板，长内容可滚动查看。

问号使用 SF Symbol `questionmark.circle`，视觉为 17pt，点击区域为 44×44pt。原因面板采用系统字体、语义颜色和滚动容器；不依赖键盘扩展以外的弹层空间。填入只插入推荐文字，不插入说明。新分析、推荐变化、草稿预估切换会关闭旧说明。
