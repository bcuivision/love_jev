# 恋爱吗 · 微信键盘分镜 v2

本套设计按最新需求收敛：日常使用全部发生在微信键盘内，后端自动选择一条回复，亲密度按需展开。视觉采用克制的灰白键帽、系统字体和蓝色动作。

## 分镜

| 图片 | 状态 | 交互 |
| --- | --- | --- |
| [01-auto-context.png](01-auto-context.png) | 自动理解当前聊天 | 已启用权限后，在确认的微信单聊中获取当前可见内容；用户可继续打字 |
| [02-one-recommendation.png](02-one-recommendation.png) | 一句推荐 | 后端完成策略判断和候选筛选；用户轻点「填入」，再使用微信发送 |
| [03-intimacy-details.png](03-intimacy-details.png) | 可选关系详情 | 轻点小型亲密度入口查看依据；收起后回到普通键盘 |

默认展示第 2 张的结构。第 1 张是后台处理中状态，第 3 张为可选支线，不是每次聊天都要完成的步骤。对话、分数和判断均为虚构演示内容。

## 平台说明

图片展示拟议 Android 自动识屏方案，使用 Apple 风格的视觉语言；不代表 iPhone 键盘具有自动截图权限。Android 方案需要首次启用输入法和辅助截图服务，并在实际演示手机、微信版本上验证单聊识别与截屏。截图只覆盖当前可见内容。

用户提供的 iPhone / iOS 26.6.1 / 微信 8.0.78 尚未实机核验。iOS 公开键盘 API 无法完成所要求的自动截取微信聊天。当前 KeyboardKit 核心以闭源二进制发布；中文 Android 底座建议研究 Fcitx5 Android。

本轮完成的是图片和实现设计；没有修改上游仓库、完成原生构建或验证自动截图。具体来源、源码接入点、上下文处理和接口契约见 [implementation-brief.md](implementation-brief.md)。

## 素材与复现

图片通过内置 ImageGen 生成，PNG 原图保留。完整生成说明和参考图接续说明见 [prompts.md](prompts.md)。旧的手动导入分镜保留在相邻的 `../storyboard/` 目录，本套取代旧交互方向。

实施时保留中文拼音候选词、正常编辑、键盘切换以及授权设置。默认不显示多种语气、三选一、上传入口或独立分析页面。
