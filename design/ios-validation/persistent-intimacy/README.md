# 常驻亲密度与独立影响预估

2026-09-27，iPhone 17 Pro / iOS 26.0 模拟器；截图为明确标注的示例数据。

- `loading.png`：推荐生成中，亲密度 72 和进度条仍然可见。
- `recommendation.png`：当前亲密度 72，推荐旁独立显示预计 +8 分；尚未填入草稿。
- `draft-cold.png`：当前亲密度仍为 72，草稿预计 −8 分，发送后预计 64 分；当前值不会被预测结果覆盖。

验证：App、键盘和广播扩展模拟器构建成功。新增 Swift 测试覆盖常驻分数、预测与当前值分离、0–100 边界、未知分数、先评分后推荐、推荐失败保留分数，以及迟到评分隔离。后端测试验证评分在生成回复之前发出、HTTP 增量到达和评分之后的失败事件。

实际 Swift `AssistantClient` 与临时 Node 服务完成流式联调：服务先发送 72 分，收到客户端已经显示该分数的确认后，才允许完成推荐；联调通过。此测试使用合成响应，未调用真实模型。

同一输入文档在当前进程中可保留上次分数；不将分数写入持久存储。新输入文档清除旧分数。真实微信中的输入文档复用、广播与网络表现仍需安装新版后真机验收。
