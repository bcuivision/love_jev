## Board 1 — Context import

Use case: ui-mockup. Create a polished high-fidelity Chinese mobile product storyboard for the hackathon product “恋爱吗”, an Android companion app plus a custom assistant keyboard used inside WeChat. This is ONE COHERENT PRODUCT AND A SEQUENTIAL DEMO, not competing design alternatives. All conversations, people, and numeric values are fictional examples. Current date anchor is 2026-09-27; avoid dates and OS times in the artwork.
Canvas: a 2048 x 1536 landscape storyboard board, three perfectly aligned tall flat mobile app-content screens side by side; each screen logical viewport 390 x 844. Preserve that portrait proportion. Screens are large and readable with wide outer margin and modest gutters. Board has a short clear Chinese title at top left, small sequence caption, and a small caption below each screen. No device bezels, phone bodies, notches, status bars, clocks, batteries, browser chrome, home bars, angled phones, or hands. Content only with square outside screen edges, no device shadows. A quiet warm off-white board background, crisp dark charcoal Chinese sans serif type, refined layout like a professional Figma presentation.
Design system: restrained, warm, human, competent, NOT cute dating-game pink and NOT a sci-fi dashboard. Companion app uses warm-white #FAF9F6, charcoal #242B2B, muted sage #708B7E, and terracotta/coral #D87966 accent for primary actions; 16px rounded controls, thin quiet separators, 16px logical body copy and strong readable 24px headings. Use spacing and grouping, avoid excessive nested cards. Abstract simple circular profile avatars: counterpart “小雨” muted lavender, self “我” muted ochre. Keep same identities, wording, app name, and colors across all panels.
When showing WeChat, reproduce a recognizable generic Android WeChat conversation CONTENT area as a conceptual mock, with gray #EDEDED chat canvas, header “小雨”, back chevron and ellipsis, white incoming chat bubbles on left with the lavender avatar, light green #95EC69 outgoing bubbles on right with ochre avatar. A normal WeChat composer remains ABOVE the custom keyboard, with microphone icon, blank rounded text entry, emoji icon and plus icon. The custom keyboard occupies ONLY the lower ~360 logical pixels of the viewport. It must look like a real input method occupying the keyboard region, not a floating app over the conversation. Keyboard header has “恋爱吗” at left, small “小雨 ∨” relationship selector, and a small keyboard-switch icon. It is an auxiliary suggestion keyboard, no need for full QWERTY except if a screen explicitly calls for the regular keyboard.
Limit visible text to exact specified short Chinese phrases. All Chinese glyphs must be crisp and accurate. No English text beyond a small “DEMO STORYBOARD” in board header if desirable. No stock illustrations, mascot, marketing hero, giant hearts, unrelated features, app store claims, probability-of-romance promises, or automatic WeChat reading/sending. All buttons should have clear primary hierarchy. Footnote on board: “概念分镜 · 聊天与分数均为示例”.
Historical chat, exact chronological text:
我：“你说的那家咖啡店，后来去了吗？”
小雨：“还没呢，最近一直加班。”
我：“那等你忙完，有空去坐坐。”
小雨：“好呀，忙完再说～”
New incoming message later: 小雨：“终于忙完了，想出去走走。”
New composed reply at end: 我：“要不要一起喝杯咖啡？我知道一家不错的。”

Primary request: first storyboard board, titled “从聊天截图，建立你们的上下文”, subtitle “恋爱吗 · 准备与导入”. Three screens show sequential states 01, 02, 03. These are THREE STATES of one workflow, not three alternative designs.
SCREEN 01 — small outside label “01  导入聊天截图”.
Companion app home inside screen: subtle wordmark “恋爱吗” and small outline heart logo at top. Large headline “这句话，怎么接？” Subtitle “先让我了解你们聊到了哪里”. Main content is a tastefully framed tall thumbnail of the provided fictional WeChat historical conversation (not a blank placeholder), with one small image count label “1 张截图”. Bottom primary coral button “选择聊天截图”, secondary plain text “粘贴聊天文字”. Small helper “只分析你主动提供的内容”. Only one primary action.
SCREEN 02 — outside label “02  确认双方与内容”.
Companion app review screen header “确认聊天内容”. A slim setting row “右边是我” with selected state and “交换双方” as small secondary action. Show the four historical messages in clearly differentiated left/right chat bubbles, full exact text, generous line spacing. A subtle annotation “已识别 4 条消息 · 可点按修改”. Bottom coral button “确认并分析”.
SCREEN 03 — outside label “03  上下文准备就绪”.
Companion app clean completion/context screen header “已记住这段聊天”. Lavender avatar next to “小雨”, quiet line “4 条消息已整理”. Middle strong text “有来有回，邀约尚未确定”. Two lightweight evidence lines quoting “好呀，忙完再说～” and explaining “对方愿意延续，但还没有具体约定”. An understated sage information block reads “下一步：回微信，切换到恋爱吗键盘”. Single bottom coral button “完成”. Small note “需先在系统设置中启用键盘”.
Outside captions under each respective screen: “选取连续截图，补充历史对话” ; “核对谁说了什么，避免误判” ; “完成后，手动回到微信”.
Keep preparation separate from keyboard interaction. Do NOT show an automatic app-launch button or automatic chat-sync capability.
